# AbbyMath

A Grade 5 mathematics site aligned to **The Ontario Curriculum, Grades 1–8: Mathematics (2020)**.

The splash page presents the full Grade 5 curriculum organized by strand:

- **A** — Social-Emotional Learning Skills & Mathematical Processes
- **B** — Number (Number Sense · Operations)
- **C** — Algebra (Patterns · Equations & Inequalities · Coding · Mathematical Modelling)
- **D** — Data (Data Literacy · Probability)
- **E** — Spatial Sense (Geometric & Spatial Reasoning · Measurement)
- **F** — Financial Literacy (Money and Finances)

Content is paraphrased for families and students. For official specific expectations, see the
[Ontario Ministry of Education curriculum](https://www.dcp.edu.gov.on.ca/en/curriculum/elementary-mathematics).

## Local preview

```bash
cd AbbyMath
python3 -m http.server 8000   # then open http://localhost:8000
```

Static HTML/CSS — no build step. Hosted with GitHub Pages.
